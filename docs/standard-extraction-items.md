# 표준 과제 추출 항목

과제 이름은 `standard`다. 이 문서는 그 과제가 닫는 추출 항목을 적는다. 값 정의는 `audit_opinion.v19`(2026-10-23)다.

항목이 원문에 없으면 **누락**이다. **해당 없음**과 **제도상 없음**은 그 항목의 상태이며, 실패로 세지 않는다.

식별의 보고기간은 `current_period`와 같은 항목이다. 자산총계, 부채총계, 자본총계, 당기순이익은 `accounts`에 있다.

## 식별

| 항목 | 내용 |
| --- | --- |
| 회사명 | 문서의 회사 |
| 문서 제목 | 감사보고서 또는 연결감사보고서 |
| 기수 | 표기의 제N기 |
| 보고기간 | `current_period` |

## 12묶음

| 묶음 | 키 | 항목 |
| --- | --- | --- |
| 감사인 | `auditor` | 이 문서의 감사인. 회계법인 또는 감사반 |
| 감사의견 | `opinion` | 재무제표 감사의견. 적정, 부적정, 거절 |
| GAAP | `gaap` | 적용 회계기준. 원문과 정규화 코드 |
| 감사보고서일 | `audit_report_date` | 의견서에서 채택한 날. 창이 비면 미검출 |
| 당기 | `current_period` | 표지의 당기 표시 |
| 감사시간 | `hours` | 별지 제4호 2절의 역할 × 지표 × 기간 |
| 실시항목 | `activities` | 별지 제4호 3절의 절차 7개 |
| 커뮤니케이션 | `communications` | 별지 제4호 4절. 감사위원회 여부와 회차 |
| 계정 | `accounts` | 연구 계정 13개. 당기·전기 금액 |
| 내부회계 | `icfr` | 같은 문서의 내부회계 의견 |
| 계속기업 | `going_concern` | 당기 중요한 불확실성. 있으면 1, 없으면 0 |
| 종속기업 | `subsidiary` | 연결 문서의 종속기업 수 |

### 감사시간 `hours`

한 칸은 역할, 지표, 기간의 조합이다. 라벨이 격자에 없으면 `unmapped`다.

| 축 | 값 |
| --- | --- |
| 역할 | 품질관리검토자, 업무수행이사, 등록공인회계사, 수습공인회계사, 수주산업·건설계약 전문가, 전산·가치평가·세무 전문가, 합계, 기타 |
| 지표 | 투입인원수, 감사시간, 분·반기검토, 합계 |
| 기간 | 당기, 전기 |

### 실시항목 `activities`

| 절차 | 키 | 내용 |
| --- | --- | --- |
| 전반감사계획 | `planning` | 실시 내용 |
| 현장감사 | `fieldwork` | 실시 내용 |
| 재고자산 실사 | `inventory_observation` | 시기, 장소, 대상 |
| 금융자산 실사 | `financial_asset_observation` | 시기, 장소, 대상 |
| 외부조회 | `external_confirmations` | 금융거래, 채권채무, 변호사, 기타 |
| 지배기구와의 커뮤니케이션 | `tcwg_communication` | 실시 내용. 4절 회차와는 별개 |
| 외부전문가 | `expert` | 실시 내용 |

### 커뮤니케이션 `communications`

| 필드 | 내용 |
| --- | --- |
| `has_audit_committee` | 감사위원회 여부 |
| `items` | 회차 행 |

1–3절은 있고 4절만 없는 옛 공시는 제도상 없음이다.

### 계정 `accounts`

재무상태표·손익계산서의 13개다. 각 금액은 원문(`raw`), 공시 단위 수치(`value`), 단위 배수(`unit_scale`), 원 단위(`value_won`)다. `제N기` 열은 큰 기수가 당기, 작은 기수가 전기다. `당기순손실`과 `영업손실`은 음수다. 연결 문서는 연결재무제표·연결손익계산서, 별도 문서는 재무상태표·손익계산서를 본다.

| 계정 | 키 | 표 |
| --- | --- | --- |
| 자산총계 | `total_asset` | 재무상태표 |
| 유동자산 | `current_asset` | 재무상태표 |
| 재고 | `inventory` | 재무상태표 |
| 매출채권 | `receivable` | 재무상태표 |
| 장기매출채권 | `long_term_receivable` | 재무상태표 |
| 계약자산 | `contract_asset` | 재무상태표 |
| 미청구공사 | `unbilled` | 재무상태표 |
| 부채총계 | `total_liability` | 재무상태표 |
| 유동부채 | `current_liability` | 재무상태표 |
| 자본총계 | `total_equity` | 재무상태표 |
| 매출액 | `revenue` | 손익계산서. `영업수익`·`공사수익`도 이 칸이다 |
| 영업이익 | `operating_income` | 손익계산서 |
| 당기순손익 | `net_income` | 손익계산서 |

범위에서 빠지는 과목은 다음과 같다. `부채와자본총계`와 `부채및자본총계`. `비유동`·`기타`가 붙은 과목과 `유동화부채`. 계속·중단·귀속·지배·비지배·총포괄이 붙은 당기순손익. 충당이 붙은 재고. `매출원가`. `영업외`가 붙은 손익.

### 내부회계 `icfr`

같은 문서의 내부회계 leaf다. 회사의 내부회계관리제도 운영보고서는 이 항목이 아니다. 별도·연결은 그 문서의 `fs_scope`를 따른다.

| 필드 | 내용 |
| --- | --- |
| `icfr_engagement` | 감사 또는 검토 |
| `icfr_opinion_code` | 아래 코드 |
| `icfr_status` | 추출 상태 |

| 업무 | 의견 코드 |
| --- | --- |
| 감사 | 적정, 부적정, 거절. 중요한 취약점은 부적정 |
| 검토 | 적정, 한정, 거절, 중요한 취약점 |

leaf가 없을 때 제도상 없음은 비상장 개별(F001)과, 연결 의무 전인 F002(사업연도 2022년까지)다.

### 계속기업 `going_concern`

당기 중요한 불확실성이 있으면 1, 없으면 0이다. 한정·부적정·거절의 근거, 전기 인용만 있는 경우, 청산기준 강조사항만 있는 경우는 0이다.

### 종속기업 `subsidiary`

연결 문서의 종속기업 수다. 관계기업과 공동기업은 세지 않는다. 별도 문서는 `subsidiary_status=not_applicable`이고 `subsidiary_count`는 null이다.

## 12묶음 밖의 표준 항목

| 항목 | 내용 |
| --- | --- |
| 주석 목차 | 주석 개수와 제목 목록. 주석 본문은 포함하지 않음 |

## 표준 항목이 아닌 것

주석 본문 전량, 계정과목 전량, 사업보고서 본문, 별지 제4호 5절 중요성 금액, 내부회계관리제도 운영보고서.
