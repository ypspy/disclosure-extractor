# Gold Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 감사보고서 한 건의 표준 항목을, 드래그한 글자를 근거로 확인한 뒤에만 골드 칸에 저장하는 열람 책상으로 입수 화면을 바꾼다.

**Architecture:** 구역 이름과 확정 값 검증은 `capture.py`에 둔다. `save_capture`는 사람이 보낸 `confirmed`만 저장하고, 드래그 글자는 `evidence`로 남긴다. 제안 값은 쓰기가 아닌 `preview` POST가 `parse_click`으로 돌려준다. 화면은 기존 루프백 앱의 서버 HTML과 `capture.js`다. 1차와 재입수가 그 책상을 같이 쓴다.

**Tech Stack:** Python 3.11+, SQLite, pytest, ruff, 기존 `html.parser` 정리와 shadow root. 숫자는 `to_number`와 `Amount.from_cell`의 단위 계산, 글자는 `normalize_text`.

## Global Constraints

- 명세: `docs/superpowers/specs/2026-11-12-gold-desk-design.md`. 이 문서가 `docs/superpowers/specs/2026-11-11-gold-capture-design.md`의 화면 동작을 대체한다.
- subject 키, `gold_captures`, `gold_capture_units`, `gold_recaptures`, `gold_recapture_units`, 이력 기록, 1차·2차 잠금은 유지한다.
- 추출기 출력은 후보로도 보이지 않는다. `gold_labels`와 채점 코드는 호출하지 않는다.
- 문서 HTML은 구역으로 자르지 않는다. 추출기 섹션 창은 스크롤 위치도 저장 조건도 아니다.
- 태그 클릭으로 저장하지 않는다. `normalize_text()`한 드래그가 비면 저장하지 않는다. 저장 전에는 행이 바뀌지 않는다.
- 닫힌 값의 저장 코드: 문서 제목 `감사보고서`·`연결감사보고서`, 감사의견 `적정`·`한정`·`부적정`·`거절`, 회계기준 `K-IFRS`·`K-GAAP`, 인증수준 `audit`·`review`, 감사 의견 `적정`·`부적정`·`거절`, 검토 의견 `적정`·`한정`·`거절`·`중요한 취약점`, 계속기업 `1`·`0`, 감사위원회 참·거짓.
- 금액 배수는 `1`, `1000`, `1000000`, `100000000`만이다. 단위를 바꾸면 `value`와 `raw`는 두고 `unit_scale`과 `value_won`만 다시 계산한다.
- 색: 배경 `#e4dccb`, 본문 글자와 위 막대 배경 `#1c1915`, 위 막대 글자 `#f4efe4`, 레일 `#d9d0bf`, 종이 `#fbf7ef`, 칸 `#efe8d8`, 드래그 `#e7b008`, 확인 막대 `#243028` / `#f4efe4`. 글꼴은 네트워크에서 받지 않는다.
- 재입수 중 1차 쓰기 POST는 409 `재입수 중`이고 본문에 1차 값이 없다. 재입수 완료 뒤 2차 쓰기 POST는 409 `재입수가 끝났습니다`.
- 서버는 루프백만 받는다. `DART_LLM_ENABLED=false`. 네트워크와 LLM 호출을 넣지 않는다.
- 작업 트리의 `src/dart_parser/gold/capture_html.py`, `tests/test_gold_capture_html.py`, `docs/cursor-prompt-sanction-agenda.md`는 이 계획이 그 파일을 수정하라고 한 작업이 아니면 되돌리거나 커밋하지 않는다.
- 작업 끝에 `python -m pytest`와 `ruff check .`를 통과시킨다.

`capture.py`에 `FieldControl`, `field_control`, `confirm_value`를 추가한다. `parse_click`은 제안용으로 그대로 둔다. `confirm_value`는 `parse_click`을 호출하지 않는다. `known_subject(bundle, subject)`가 아니면 `None`을 반환한 뒤 `field_control`을 보지 않는다.

```python
@dataclass(frozen=True)
class FieldControl:
    kind: str
    options: tuple[tuple[str, str], ...] = ()
    blocked: str = ""


def field_control(
    bundle: str,
    subject: str,
    *,
    icfr_engagement: str | None = None,
) -> FieldControl:
    if not known_subject(bundle, subject):
        return FieldControl("text")
    if bundle == "document_title":
        return FieldControl("enum", (("감사보고서", "감사보고서"), ("연결감사보고서", "연결감사보고서")))
    if bundle == "opinion":
        return FieldControl("enum", tuple((item, item) for item in ("적정", "한정", "부적정", "거절")))
    if bundle == "gaap":
        return FieldControl("enum", (("K-IFRS", "K-IFRS"), ("K-GAAP", "K-GAAP")))
    if bundle == "icfr" and subject == "engagement":
        return FieldControl("enum", (("audit", "감사"), ("review", "검토")))
    if bundle == "icfr" and subject == "opinion":
        if icfr_engagement == "audit":
            options = ("적정", "부적정", "거절")
        elif icfr_engagement == "review":
            options = ("적정", "한정", "거절", "중요한 취약점")
        else:
            return FieldControl("enum", blocked="인증수준을 먼저 저장하세요")
        return FieldControl("enum", tuple((item, item) for item in options))
    if bundle == "going_concern":
        return FieldControl("enum", (("1", "불확실성 있음"), ("0", "불확실성 없음")))
    if bundle == "communications" and subject == "has_audit_committee":
        return FieldControl("enum", (("true", "있음"), ("false", "없음")))
    if bundle == "audit_report_date":
        return FieldControl("date")
    if bundle == "current_period":
        return FieldControl("period")
    if money_group(bundle, subject) is not None:
        return FieldControl("amount")
    if bundle in {"hours", "subsidiary"}:
        return FieldControl("number")
    if bundle == "notes_toc":
        return FieldControl("note")
    if bundle == "communications" and subject == "items":
        return FieldControl("round")
    return FieldControl("text")
```

`confirm_value`는 `normalize_text(evidence)`가 비면 `None`이다. 그 다음 `field_control`의 `kind`로 갈라진다.

- `enum`: `blocked`가 있으면 `None`. 의견·제목·기준·인증수준은 `confirmed`가 options의 값과 같을 때만 그 문자열. 계속기업은 `confirmed`가 `0` 또는 `1`일 때만 `int`. `True`/`False`는 거절. 감사위원회는 `confirmed is True` 또는 `confirmed is False`일 때만 그 값.
- `text`와 `note`: `confirmed`가 `str`이고 `normalize_text(confirmed)`가 비지 않을 때 그 문자열.
- `date`: `confirmed`가 `YYYY-MM-DD`이고 `datetime.date.fromisoformat`이 될 때만 그 문자열.
- `period`: `confirmed`가 `dict`이고 `start`·`end`가 각각 그 날짜일 때만 `{"start", "end"}`.
- `amount`: `unit_scale`이 `SCALES`에 있고 `_finite_number(confirmed)`가 `None`이 아닐 때 `raw`는 evidence 원문, `value`는 그 수, `value_won`은 `value * unit_scale`.
- `number`: `_finite_number(confirmed)`.
- `round`: `confirmed`가 `dict`이고 `normalize_text(confirmed.get("raw"))`가 비지 않을 때 `{"raw": 그 문자열}`. `date`가 없거나 `""`이면 키를 넣지 않는다. 다른 날짜 문자열이면 `None`.

```python
def _finite_number(value: Any) -> float | None:
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        return None
    number = float(value)
    if number != number or number in {float("inf"), float("-inf")}:
        return None
    return number


def _iso_date(value: Any) -> str | None:
    if not isinstance(value, str):
        return None
    try:
        return dt.date.fromisoformat(value).isoformat()
    except ValueError:
        return None
```

```python
def _post_preview(
    app: ReviewApplication,
    environ: dict[str, Any],
    start_response: Any,
    rcept_no: str,
    dcm_no: str,
    *,
    capture_pass: int = 1,
) -> list[bytes]:
    if not _host_allowed(environ) or not _origin_allowed(environ):
        return _reject(start_response)
    form = _form_body(environ)
    if not _token_ok(app.token, _one(form, "token")):
        return _reject(start_response)
    if app.store.sample(rcept_no, dcm_no) is None:
        return _json(start_response, "404 Not Found", {"error": "문서가 없습니다."})
    blocked = _ambiguous(app, rcept_no, dcm_no, start_response)
    if blocked is not None:
        return blocked
    bundle = _one(form, "bundle")
    subject = _one(form, "subject")
    if not known_subject(bundle, subject):
        return _json(start_response, "400 Bad Request", {"error": "항목이 아닙니다."})
    text = _one(form, "text")
    scale = None
    group = money_group(bundle, subject)
    if group is not None:
        scale = load_units(app.store.conn, rcept_no, dcm_no, capture_pass=capture_pass).get(group)
    engagement = None
    if bundle == "icfr":
        from dart_parser.gold.capture_store import _engagement

        engagement = _engagement(app.store.conn, rcept_no, dcm_no, capture_pass)
    control = field_control(bundle, subject, icfr_engagement=engagement)
    proposal = parse_click(bundle, subject, text, unit_scale=scale, icfr_engagement=engagement)
    payload = {
        "proposal": proposal,
        "kind": control.kind,
        "options": [{"value": value, "label": label} for value, label in control.options],
        "blocked": control.blocked,
    }
    return _json(start_response, "200 OK", payload)
```
